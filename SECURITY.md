# Security Policy

## Supported Versions

This project is pre-1.0 and does not yet maintain parallel release branches.
Security fixes are made against the latest release only.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report it privately by emailing **info@spazioit.com** with:

- A description of the vulnerability and its potential impact
- Steps to reproduce, or a proof of concept if available
- The plugin version and SonarQube Server version you tested against

You should receive an acknowledgement within a few business days. We'll work
with you to understand and address the issue, and will credit you in the
release notes when a fix is published, unless you'd prefer to remain
anonymous.
